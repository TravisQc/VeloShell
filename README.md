# VeloShell

开源、跨平台的 SSH 客户端(FinalShell 类替代品),使用 Avalonia UI + .NET 9 构建。Windows 优先,后续支持 macOS / Linux。

> 开发中。当前里程碑:连接管理 + 凭据加密存储。

## 安全模型

VeloShell 的凭据(登录密码、私钥口令)采用跨平台可移植的加密方案,不依赖任何单一操作系统 API:

- **加密链路**:主密码 → Argon2id 派生 256 位密钥 → AES-256-GCM 加密后落盘。
- **明文不落盘**:明文凭据与派生密钥永不写入磁盘;`vault.json` 中仅保存密文。
- **密钥仅驻内存**:派生密钥只保存在内存中,应用退出或凭据库锁定时立即清除,再次访问需重新以主密码解锁。
- **防篡改**:每条密文使用独立的随机 nonce,并附带 GCM 认证标签;密文被篡改会在解密时被检出并拒绝使用。
- **主密码无找回**:采用零知识设计,系统不保存主密码,也没有找回后门。**遗忘主密码将无法解密既有凭据,只能重置凭据库(清空全部已存凭据)。**

数据存储位置:`%APPDATA%\VeloShell`(Windows);其他平台对应各自的应用数据目录。
